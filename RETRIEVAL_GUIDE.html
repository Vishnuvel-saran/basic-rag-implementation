Retrieval Methods

Semantic

Vector Similarity Search

How it works: Your question is converted to an embedding vector and compared to all document vectors using cosine similarity. The most similar documents are returned.

Best for:

  • Conceptual queries
  • Understanding meaning and context
  • Queries with synonyms or paraphrasing
  • Natural language questions

What you'll see:

Results labeled with similarity scores (0.0 to 1.0), where higher is better. Each chunk shows its semantic relevance to your query.

Retrieved chunks show: - Chunk ID - Similarity score (e.g., 0.856) - Page numbers - Full chunk text
BM25

Keyword-Based Search

How it works: Your question is tokenized and matched against documents using BM25 ranking algorithm. Documents with more relevant keywords rank higher.

Best for:

  • Specific keyword queries
  • Exact term matching
  • Technical documentation
  • When you know the exact terms to search

What you'll see:

Results labeled with BM25 scores (numeric values), where higher is better. Each chunk shows how well its keywords match your query.

Retrieved chunks show: - Chunk ID - BM25 score (e.g., 8.451) - Page numbers - Full chunk text
Hybrid

Combined Ranking (RRF)

How it works: Both BM25 and Semantic searches are run. Results are intelligently fused using Reciprocal Rank Fusion (RRF) to combine keyword and semantic signals. You see the fused results plus individual results from each method.

Best for:

  • General queries (best of both worlds)
  • When you're unsure which method is best
  • Comprehensive retrieval
  • Understanding different retrieval perspectives

What you'll see:

Three sections of results:

  1. Hybrid Results (RRF Fused) - Top results after intelligent fusion. Shows RRF score and individual ranks from each method.
  2. BM25 Individual Results - Expandable section showing BM25-only rankings with scores
  3. Semantic Individual Results - Expandable section showing Semantic-only rankings with similarity scores
Hybrid results show: - Chunk ID - RRF score (fused ranking) - Individual ranks: BM25 rank #X, Semantic rank #Y - Page numbers - Full chunk text

Understanding the Results

Semantic Results

Each chunk includes a similarity score between 0.0 and 1.0:

  • 0.9+ - Highly relevant, very similar to your query
  • 0.7-0.9 - Relevant, good semantic match
  • 0.5-0.7 - Somewhat relevant, related concepts
  • <0.5 - Low relevance, weak semantic connection

BM25 Results

Each chunk includes a BM25 score:

  • Higher scores mean more keyword matches and better frequency
  • Exact keyword matches score higher than partial matches
  • Repeated keywords increase the score
  • Common words contribute less than rare keywords

Hybrid (RRF) Results

Hybrid results show multiple types of information:

  • RRF Score - The fused ranking score combining both methods
  • BM25 Rank - Position in BM25-only results (if present)
  • Semantic Rank - Position in Semantic-only results (if present)

A document that ranks well in both methods will rank even higher in the fused results.

Comparing Results Across Methods

Why Different Methods Give Different Results

The three methods use completely different ranking algorithms:

Aspect Semantic BM25 Hybrid
Signal Type Meaning & context Keywords & frequency Both combined
Handles Synonyms Yes No Yes
Exact Keywords Not prioritized Highly prioritized Balanced
Best Use Case Conceptual queries Specific keywords General queries

Example Query: "How do I optimize database performance?"

  • Semantic: Finds documents about performance improvement, tuning, efficiency - even if they don't use the word "optimize"
  • BM25: Finds documents with exact keywords: "optimize", "database", "performance" - highest match if all three appear together
  • Hybrid: Combines both - ranks documents that have the keywords AND semantic relevance higher

Tips & Recommendations

💡 When to Use Each Method

Choose Semantic when:

  • Asking natural language questions
  • Using synonyms or paraphrased terms
  • Looking for related concepts
  • Not sure about exact keywords

Choose BM25 when:

  • Searching for exact technical terms
  • Looking for specific keywords
  • You know exactly what you're searching for
  • Dealing with technical or specialized vocabulary

Choose Hybrid when:

  • You want the best of both worlds
  • You're not sure which method is best
  • Comparing different retrieval approaches
  • You want the most robust results

API Reference

Sending Requests

You can also query the API directly with the retrieval method parameter:

curl -X POST http://localhost:8000/query \ -H "Content-Type: application/json" \ -d '{ "question": "Your question here", "top_k": 5, "retrieval_method": "semantic" }'

Valid values for retrieval_method:

  • "semantic" - Vector similarity search
  • "bm25" - Keyword-based search
  • "hybrid" - Combined RRF fusion
